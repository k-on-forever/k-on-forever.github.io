# 文章撰写提示（Hexo / Butterfly）

本文件仅作本地备忘，**不会**被 `hexo generate` 发布到网站（位于项目根目录 `docs/`）。

## 内容层面

### `description`（摘要 / SEO）

- 在文章 **front matter** 里写一行 `description: ...`，用于主题摘要、部分 SEO 与分享卡片。
- 建议 **1～2 句**，说明「这篇讲什么、适合谁」，避免和标题完全重复。
- 示例：

```yaml
---
title: 某篇标题
date: 2026-03-20 12:00:00
description: 一句话说明全文范围与价值，例如：MySQL 事务隔离级别与锁的笔记，含表与案例。
---
```

### 首段结构（长文建议）

- 第一段用 2～4 行写清：**背景 / 本文覆盖范围 / 不覆盖什么**，再进入目录。
- 小节标题尽量用 Markdown 标题 **`##` / `###`**，少用纯行首的 `(1)`、`①` 当「假标题」，否则目录与跳转不友好。

### `cover` / `keywords`

- 有封面图时：`cover: /img/xxx.jpg`（路径与 `source` 对应）。
- 若主题或插件支持 `keywords`，可补：`keywords: [MySQL, 事务]`。

## 代码块（重要）

- **请勿让工具自动「整理」正文里的 ` ``` ` 代码**：缩进、换行以你本地为准；批量替换容易整站观感异常。
- 若代码在网页上显示异常，优先检查 **是否混用 Tab/空格** 或主题高亮，而不是改全文。

## 图片与媒体（你无需改习惯）

- 正文里照常写 `![说明](url)` 或 `<img>` 即可；**样式由 `source/css/custom.css` 统一**（圆角、阴影、最大宽度）。
- 若需「图注」，用 HTML：

```html
<figure>
  <img src="..." alt="说明" />
  <figcaption>图说明文字</figcaption>
</figure>
```

- 嵌入 B 站 / YouTube 等：直接贴 iframe 或主题提供的短代码，**同样会套用嵌入媒体样式**。

## 新文章模板（可复制）

```yaml

date: 2026-03-20 12:00:00
updated: 2026-03-20 12:00:00
description: 一句话摘要。
categories:
  - 分类
tags:
  - 标签1
  - 标签2
# cover: /img/cover.jpg
---

这里写开篇说明。

## 第一节

正文……
```
